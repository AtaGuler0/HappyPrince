# Mutlu Prens — Kırlangıç'ın Bir Gecesi

Oscar Wilde'ın *Mutlu Prens* masalından uyarlanan kısa bir Unity prototipi. Oyuncu Kırlangıç'ı uçurarak Prens'in yakutunu yoksul terzi kadına götürür ve hasta çocuğa yardım eder.

## Çalıştırma

Projeyi Unity Hub'da açın, `Assets/_MutluPrens/Scenes/MutluPrens_Bolum1.unity` sahnesini açıp Play'e basın. Ana menüden **Oyuna Başla**'yı seçin.

## Kontroller

- **WASD:** uçuş yönü · **Space / Ctrl:** yüksel / alçal
- **Shift:** hızlan · **E:** etkileşim · **Esc:** duraklat

Unity sürümü: **6000.4.0f1**.
